# defiufo.site

Proof-of-work page for DeFi Danny (@defiufo).

## Deploy on Vercel

1. Create a Vercel account at https://vercel.com/signup (GitHub login is easiest).
2. Import this repo.
3. Framework: Other. Output: the repo root. No build command needed.
4. Deploy. Add a custom domain later if you want.

Local preview: open `index.html` in a browser.
